# Inbox

`inbox/` は未整理の一時置き場。

## ルール

- 一時メモ、未分類URL、受領直後の断片を置いてよい。
- 正式な判断、設計、成果物に使う前に、SRC / INF / KNW / WRKへ変換する。
- inbox内のメモを下流作業の根拠にしない。

## 整理時の分岐

- 元ネタなら `sources/` または `files/`。
- 抽出情報なら `info/`。
- 再利用ルールなら `knowledge/`。
- 作業判断や検証なら `work/`。
- 証跡なら `evidence/`。

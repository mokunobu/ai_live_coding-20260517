# KNW-010 参照サイト三段階分解

## 目的

良いサイトを集めるだけで終わらせず、AIブリーフやレビューに使えるカードへ分解する。

## 核となる主張

参照サイトは `サイト全体 -> セクション -> 判断カード` の三段階で分解すると、丸コピーではなく再利用できる知識になる。

## 適用範囲

- KLG会社HPの参照サイト収集。
- Xやギャラリーから見つけたデザインのカード化。
- AIにデザイン指示を渡す前の整理。

使わない場面:
- スクリーンショットやコピーをそのまま流用する。
- 掲載サイトを品質保証として扱う。

## 私の解釈

- サイト全体カードは、業種、目的、導線、情報量、下層ページの有無を見る。
- セクションカードは、ヒーロー、サービス、プロセス、事例、CTA、フォームなどの役割を見る。
- 判断カードは、余白、階層、可読性、コントラスト、ブランド表現、状態、フローなど、別案件でも使える知識にする。

## 再現手順

1. 参照元URLを `SRC` に残す。
2. 候補サイトのページ構成と観察事実を `INF` に抽出する。
3. 使える理由を1つずつ `KNW` に分ける。
4. 使わない理由、KLGに合わない理由も書く。
5. AIブリーフでは、サイト名ではなく必要な `KNW` を指定する。

## 判断基準

採用条件:
- 参照サイトから実制作に使える考え方を抽出する。

不採用条件:
- 単なる好み、雰囲気、かっこよさしか説明できない。

失敗条件:
- 1カードにヒーロー、CTA、配色、モーション、コピーが混ざる。
- 参照サイトの見た目をKLGへそのまま移す。

## AIへの指示 / 作業への使い方

```text
参照サイト名だけではなく、抽出済みの判断カードを使ってください。サイト全体、セクション、判断基準を分け、KLGに使う要素と使わない要素を明示してください。
```

## レビュー質問

- これはサイト全体、セクション、判断基準のどの粒度か。
- KLGに使う理由と、使わない理由が分かれているか。
- AIへの具体的な指示に変換できるか。

## 検証 / 完了条件

- 参照サイト1件から、少なくとも1つの `INF` と1つの `KNW` が作れる。
- MOCから元ネタ、抽出情報、判断カードへ戻れる。

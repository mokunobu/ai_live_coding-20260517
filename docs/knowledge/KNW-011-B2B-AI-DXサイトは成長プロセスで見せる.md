# KNW-011 B2B AI DXサイトは成長プロセスで見せる

## 目的

KLGのAI/DX/研修/実装支援を、バラバラのメニューではなく、成長プロセスとして理解できるようにする。

## 核となる主張

KLGの会社HPでは、サービスを単列に並べるより、知識が根づき、育ち、成果になる流れで見せる方が社名思想と事業説明を接続しやすい。

## 適用範囲

- トップページのサービス構成。
- サービス一覧、プロセス図、CTA。
- 会社紹介と事業説明をつなぐセクション。

使わない場面:
- 実対応範囲が未確認のサービスを広く見せる。
- 成果保証のように見える表現。

## 私の解釈

- KLG向けの基本構成は `診断 -> 整理 -> 学習 -> 実装 -> 定着 -> 成果`。
- 木のメタファーを使うなら、`根=知識基盤`, `幹=伴走支援`, `枝=AI/DX/研修/開発`, `実=業務成果` と対応づける。
- サービス名より先に、顧客が今どの段階にいるかを示すと相談しやすい。

## 再現手順

1. KLGの提供範囲を確認する。
2. 提供範囲を成長プロセスへ並べる。
3. 各段階に、顧客課題、支援内容、成果物、CTAを1つずつ置く。
4. 成果保証に見える表現を避ける。

## 判断基準

採用条件:
- AI/DX/研修/開発を一つの思想で束ねたい。
- 訪問者に相談開始位置を選ばせたい。

不採用条件:
- サービス範囲がまだ未確定で、プロセス化すると誤解を生む。

失敗条件:
- 木の図解が複雑で読めない。
- 抽象的な思想だけで、問い合わせ導線が弱い。
- 実績未確認の成果を断定する。

## AIへの指示 / 作業への使い方

```text
KLGのサービスは、診断、知識整理、研修/伴走、実装、定着、成果の流れとして構成してください。木のメタファーは、根=知識基盤、幹=伴走、枝=支援領域、実=成果として使い、単なる装飾にしないでください。
```

## レビュー質問

- 訪問者は自分が相談すべき段階を選べるか。
- 社名思想とサービス説明がつながっているか。
- 成果保証に見える表現がないか。

## 検証 / 完了条件

- サービス構成が1つのプロセスとして説明できる。
- 各段階にCTAまたは次アクションがある。

# KNW-014 参照ギャラリー使い分け

## 目的

参照サイト探しで迷走しないように、見るサイトを目的別に使い分ける。

## 核となる主張

国内ギャラリー、海外SaaSギャラリー、X起点デザイン、プロダクトUI集は、同じ「参考」ではなく、抽出すべき知識が異なる。

## 適用範囲

- KLG会社HPの参照収集。
- AIデザインブリーフ作成。
- 参照サイトの採否判断。

使わない場面:
- 具体的な実装要件がまだなく、方向性だけを広げる発散段階。

## 私の解釈

- 国内ギャラリー: 日本語可読性、企業サイトの信頼感、業種分類、下層ページを確認する。
- 海外SaaSギャラリー: CTA、料金/導入/事例/デモ導線、プロダクト説明、B2Bの情報密度を確認する。
- X起点デザイン: ヒーロー、モーション、UIの気持ちよさ、細部の発想を確認する。
- プロダクトUI集: フォーム、状態、ナビゲーション、オンボーディングなど、操作フローを確認する。

## 再現手順

1. 探す目的を1つ決める。
2. 目的に合うギャラリーだけを見る。
3. 候補は `SRC` へ入れ、実サイトURLと観察事実を残す。
4. `KNW-010` に従って、サイト、セクション、判断カードへ分解する。

## 判断基準

採用条件:
- 参照サイトの数が増え、選定軸が曖昧になっている。
- AIに渡す参照情報を絞りたい。

不採用条件:
- すでにKLG向けの具体的なサイト候補が決まっている。

失敗条件:
- かっこいいサイトを大量に集めるだけで、使えるカードが増えない。
- 国内企業サイトの信頼感と海外SaaSの派手さを混ぜて、方向性がぶれる。

## AIへの指示 / 作業への使い方

```text
参照元は目的別に分けて使ってください。日本語の信頼感は国内ギャラリー、B2B導線はSaaSギャラリー、UIの細部はX起点/プロダクトUI集から抽出し、各参照をKLGに使う理由と使わない理由を明示してください。
```

## レビュー質問

- この参照は何を見るためのものか。
- KLGに使う要素は、コピー、構成、導線、UI、動きのどれか。
- 使わない要素も明示されているか。

## 検証 / 完了条件

- 参照候補ごとに目的が付いている。
- AIブリーフに渡す参照が3-5件へ絞れる。

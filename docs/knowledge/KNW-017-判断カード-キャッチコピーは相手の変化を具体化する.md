# KNW-017 判断カード キャッチコピーは相手の変化を具体化する

## 目的

AIっぽい、ダサい、心が動かないキャッチコピーを避けるため、コピーの判断基準を定義する。

## 核となる主張

キャッチコピーは、企業の思想をきれいに言うものではなく、相手が抱えている未整理な困りごとを、KLGと関わった後の具体的な変化へつなげる言葉にする。

## 適用範囲

- 会社サイトのファーストビュー。
- サービス見出し。
- 問い合わせCTA。
- StitchやAIに渡す生成プロンプト。

使わない場面:
- 会社名タグラインだけを短く定義する段階。
- 実績、対象顧客、提供範囲が未確認で言い切れない内容。

## 判断基準

採用条件:
- 誰に向けた言葉か分かる。
- 読者の困りごとが見える。
- KLGが何をするのか分かる。
- 関わった後の変化が分かる。
- 競合サイトに載せても違和感がない言葉ではない。
- 15-30文字程度の短い案と、補足コピーで役割分担できる。

不採用条件:
- `未来`, `可能性`, `価値`, `伴走`, `DX`, `成果` だけで成立している。
- 何をする会社か説明文を読まないと分からない。
- 会社視点の自己紹介で終わっている。
- 実績未確認なのに成果を断定している。
- しゃれた言葉に寄せて、相談者の痛みが消えている。

## 再現手順

1. 誰の言葉かを決める。
2. その人の困りごとを一文で書く。
3. KLGが実際にできる支援だけを書く。
4. 支援後の変化を、成果保証にならない範囲で書く。
5. 比喩を使う場合は、業務上の変化へ接続する。
6. 10案以上書き、最初のきれいな案を捨てる。
7. TextLintでAIっぽい構造を検出する。
8. 声に出して読んで、リズムと引っかかりを確認する。

## 型

### 悩みから入る

`AIを入れたのに、仕事が変わらない。`

使う場面:
- AI/DX導入済みだが定着していない顧客。

### 変化から入る

`使われない知識を、動く仕事に変える。`

使う場面:
- KLGの社名思想と業務改善を接続したいとき。

### 対象者から入る

`AI活用を現場任せにしない会社へ。`

使う場面:
- 経営者、DX責任者、研修担当者に向けるとき。

## KLG向け禁止語

- 未来を創る
- 可能性を広げる
- DXを加速する
- AIで変革する
- 伴走する技術パートナー
- 価値を最大化する
- 成果を収穫する

禁止理由:
- 単体では誰の課題も示さない。
- 競合でも使える。
- AI生成っぽい安全な一般論へ寄る。

## KLG向け使用候補語

- 使われない知識
- 業務に残る
- 現場に戻る
- 言葉にする
- 仕組みにする
- 研修で終わらせない
- AI導入後の空回り
- 属人化
- 引き継げない判断
- 動く手順

## AIへの指示 / 作業への使い方

```text
KLGサイトのキャッチコピーは、抽象語を避け、相談者の困りごとと支援後の変化を具体的に書いてください。未来、可能性、価値、伴走、DXを加速、成果を収穫などの一般語だけで成立する案は不採用です。10案以上出し、最初のきれいな案を捨て、TextLintでAIっぽい構造を確認してください。
```

## レビュー質問

- 誰に向けた言葉か分かるか。
- 読者が「自分のことだ」と思う課題があるか。
- 比喩が業務上の変化に接続しているか。
- 競合企業に載っていても成立してしまわないか。
- 実績未確認の成果を断定していないか。
- TextLintでAIっぽい構造が出ていないか。

# KNW-009 判断カード AIっぽさ回避

## 目的

AI生成サイトにありがちな平均的で意図の薄い表現を避け、KLGの文脈に合うデザインへ寄せる。

## 核となる主張

AIっぽさは特定の装飾の問題ではなく、案件固有の意図がない平均表現として現れる。

## 適用範囲

- AIデザイン依頼。
- AI生成後のレビュー。
- ヒーロー、カード、背景、アイコン、アニメーション。

## 確認済み事実

- 複数の出典で、AI生成デザインは曖昧な入力や平均化により似た見た目へ収束しやすいと説明されている。
- AIっぽさの例として、青紫グラデーション、丸いカード、抽象オブジェクト、意図のない装飾、流行要素の寄せ集めが挙げられている。
- Shuffleは、AI生成サイトが似る理由として、曖昧なプロンプト、レイアウト構造、制約、視覚意図の不足を挙げている。
- AI生成UIの出典では、静的な1画面、状態不足、フロー不足、ハードコードされた値が問題になると説明されている。

## 私の解釈

- AIっぽさを避けるには、禁止表現を列挙するだけでなく、代わりに何を使うかを指定する必要がある。
- KLGでは、抽象的なAI未来感ではなく、知識、成長、実務、支援プロセス、成果の構造を見せる方が合う。

## 再現手順

1. 生成前に禁止表現を明記する。
2. 代替表現として、実務的な図解、支援プロセス、知識の樹形図、実績情報、読みやすいタイポグラフィを指定する。
3. 生成後に、各装飾が何の意味を持つか確認する。
4. 意味を説明できない装飾は削る。
5. 見た目だけでなく、状態、フロー、トークン、レスポンシブの不足も確認する。

## 判断基準

採用条件:
- AIで初期案を作る。
- 参照サイトをもとにデザイン方向を出す。

不採用条件:
- 生成物がすでに明確なブランドルールと実装済みデザインシステムに沿っている。

失敗条件:
- 青紫グラデーションが主役。
- 発光する抽象球体、脳、回路、宇宙背景がある。
- 全セクションが角丸カード。
- 英語の抽象スローガンだけが大きい。
- 事業内容より雰囲気が先に来る。
- トップの1枚絵だけ整っていて、下層ページや問い合わせ状態に一貫性がない。

## AIへの指示 / 作業への使い方

```text
AIっぽい汎用表現を避けてください。青紫グラデーション、発光オブジェクト、脳・回路・宇宙背景、ガラスカード多用、意味の薄い英語スローガンは禁止です。代わりに、KLGの社名由来である「知識が木を育て、実りになる」構造を、支援プロセス、樹形図、情報階層、余白、タイポグラフィで表現してください。
```

## レビュー質問

- この表現はKLGである理由があるか。
- AI/DXっぽいだけの装飾になっていないか。
- 事業、思想、導線のどれかを助けているか。
- 状態、フロー、トークンが設計されているか。

## 検証 / 完了条件

- 各装飾の意味を説明できる。
- KLG固有の社名思想や事業内容に接続している。

# KNW-006 判断カード タイポグラフィと可読性

## 目的

文字を画像的な飾りではなく、情報を正確に読ませるシステムとして設計する。

## 核となる主張

タイポグラフィは雰囲気作りではなく、情報の階層、読みやすさ、信頼感を支える仕組みである。

## 適用範囲

- 見出し、本文、注釈、ナビゲーション、CTA。
- 日本語中心の会社HP。
- 画像上のテキストや英語装飾が多い案。

## 確認済み事実

- WIREDの記事は、AIが文字を読みやすさのシステムではなく画像的に扱う限界を指摘している。
- NN/gは、視覚階層を作る手段としてタイプサイズや色、配置を挙げている。
- デザインシステムの出典では、タイポグラフィや色を役割と再利用可能なルールで扱う考え方が示されている。

## 私の解釈

- KLGの会社HPは日本語で信頼を作る必要があるため、英語の装飾コピーや極細フォントで雰囲気を作るより、読みやすい日本語の階層が重要。
- AIにはフォント名だけでなく、文字量、行間、1行の長さ、見出しと本文の差を指定する必要がある。

## 再現手順

1. 日本語本文を中心に、読みやすいフォントと太さを選ぶ。
2. H1、H2、H3、本文、補足のサイズ差を決める。
3. 1行が長すぎないよう本文幅を制御する。
4. 画像内テキストは避け、HTMLテキストで扱う。
5. 見出し、本文、補足、CTAのタイプスケールをトークンとして固定する。

## 判断基準

採用条件:
- 信頼性、説明力、読みやすさを優先する。
- サービス内容や会社思想を丁寧に伝える。

不採用条件:
- 装飾的な文字演出が、可読性やアクセシビリティを下げる。

失敗条件:
- 極細フォントで本文が読みにくい。
- 英語見出しが大きく、日本語説明が小さすぎる。
- 画像内テキストが多く、レスポンシブや読み上げに弱い。
- ページごとに本文サイズ、行間、見出しサイズが微妙にずれる。

## AIへの指示 / 作業への使い方

```text
日本語の可読性を最優先してください。英語の装飾コピーを主役にせず、H1/H2/本文/補足のサイズ差と行間を明確にし、本文幅を読みやすく制御してください。CTAや重要本文は画像内テキストにしないでください。
```

## レビュー質問

- 日本語だけ読んでも意味が通るか。
- 見出しと本文の階層が分かるか。
- モバイルで長い見出しが破綻していないか。
- 同じ役割の文字スタイルが全ページで揃っているか。

## 検証 / 完了条件

- 日本語本文が読みやすい。
- 画像内テキストに重要情報を閉じ込めていない。

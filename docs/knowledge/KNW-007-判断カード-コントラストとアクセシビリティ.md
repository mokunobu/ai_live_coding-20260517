# KNW-007 判断カード コントラストとアクセシビリティ

## 目的

見た目の雰囲気より、必要な情報を誰でも読める状態を優先する。

## 核となる主張

コントラストは印象調整ではなく、情報を読める状態に保つ最低条件である。

## 適用範囲

- 文字色と背景色。
- 画像上のテキスト。
- CTA、リンク、フォーム、エラー表示。
- PC/SP両方の表示。

## 確認済み事実

- W3C WCAG 2.2のContrast Minimumは、通常テキストで 4.5:1、大きな文字で 3:1 のコントラスト比をAA基準として説明している。
- NN/gは、コントラストを差異や機能の違いを伝える視覚原則として説明している。
- AI生成UIの出典では、低いコントラスト、alt欠落、見出し階層不備、キーボード操作不足が起こりやすいと説明されている。

## 私の解釈

- AI生成案は薄いグレー文字、画像上の白文字、淡いグラデーション背景を使いがちで、見た目は軽くても読みにくい場合がある。
- KLGでは信頼と実務感が重要なので、読みにくい淡さより、明確に読める落ち着いたコントラストを優先する。

## 再現手順

1. 本文、補足、リンク、CTA、フォームラベルのコントラストを確認する。
2. 画像上の文字は、背景が変わっても読める処理を入れるか、画像外へ出す。
3. 色だけで状態を伝えず、文言や形も併用する。
4. フォーカス状態、エラー状態、ホバー状態も確認する。
5. 画像の代替テキスト、見出し階層、キーボード操作、フォームエラー文言を確認する。

## 判断基準

採用条件:
- 公開サイトとして、読みやすさと操作しやすさを担保したい。

不採用条件:
- ブランド表現として淡い配色を使うが、本文やCTAの可読性が下がる。

失敗条件:
- 薄いグレー本文。
- 背景画像の上に文字を直接置いて読みにくい。
- CTAと通常リンクの違いが分からない。
- フォーカス状態が見えない。
- エラー、完了、無効、読み込み中の状態が色だけで表現されている。

## AIへの指示 / 作業への使い方

```text
WCAG 2.2 AA相当を目安に、本文と背景のコントラストを十分に確保してください。薄いグレー文字、画像上の読みにくい白文字、色だけで状態を伝える表現は避けてください。リンク、CTA、フォーム、フォーカス状態も見えるようにしてください。
```

## レビュー質問

- 本文は長く読める濃さか。
- CTAは他の要素と区別できるか。
- 色覚や画面環境に左右されすぎないか。
- キーボードだけで主要導線をたどれるか。
- フォームのエラー内容がテキストで分かるか。

## 検証 / 完了条件

- 通常テキストと背景のコントラストがAA相当を満たす。
- CTA、リンク、フォーム状態が視認できる。
- focus、error、disabled、loading、successの状態が確認できる。

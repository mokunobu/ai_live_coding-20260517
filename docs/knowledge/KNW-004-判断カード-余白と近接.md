# KNW-004 判断カード 余白と近接

## 目的

余白を装飾ではなく、情報のまとまりと優先順位を伝える構造として使う。

## 核となる主張

余白は「何もない場所」ではなく、関連する情報を近づけ、別の情報を離すための意味のある構造である。

## 適用範囲

- セクション設計。
- カード、フォーム、サービス一覧、プロセス図。
- モバイルで情報が詰まって見える画面。

## 確認済み事実

- NN/gはゲシュタルト原則として、近いものは同じグループとして認識されやすいと説明している。
- MUUUUU.ORGは、レイアウト整合性、情報階層、導線設計、コンテンツとビジュアルのバランスを掲載判断の観点に含めている。
- AI生成UIの出典では、単一のデスクトップ画面ではよく見えても、レスポンシブ時に破綻することがあると説明されている。

## 私の解釈

- AI生成デザインは、全要素を同じ間隔で並べてしまい、何が一まとまりか分かりにくくなることがある。
- KLGでは、支援領域、支援プロセス、会社情報、問い合わせ導線のまとまりを余白で分けると、誠実で理解しやすい印象になる。

## 再現手順

1. 関連する要素同士を近づける。
2. 別テーマの要素間は広めに空ける。
3. セクション内余白とセクション間余白に差をつける。
4. モバイルで、見出し、本文、CTA、次セクションが詰まりすぎていないか見る。
5. 画面幅が変わっても、近い要素と離す要素の関係が崩れていないか見る。

## 判断基準

採用条件:
- 情報のまとまりを視覚的に伝えたい。
- テキスト量が多く、読みやすさを上げたい。

不採用条件:
- 余白を広げることで重要情報がファーストビューから消え、何の会社か分からなくなる。

失敗条件:
- すべてのカードが同じ余白で、優先順位が見えない。
- 関連しない要素が近く、関係があるように見える。
- 画面が広いだけで情報密度が足りない。
- PCでは整って見えるが、SPでは見出し、本文、CTA、画像のまとまりが崩れる。

## AIへの指示 / 作業への使い方

```text
余白は装飾ではなく情報のまとまりを示すために使ってください。関連する要素は近く、別テーマのセクションは十分に離し、セクション内余白とセクション間余白に明確な差をつけてください。
```

## レビュー質問

- どの要素が一まとまりか、説明なしで分かるか。
- セクションの切り替わりが余白で分かるか。
- 余白が広いだけで中身が薄く見えていないか。
- PC/SPで同じ情報関係が保たれているか。

## 検証 / 完了条件

- PC/SP両方で情報のまとまりが分かる。
- 同じ役割の余白が揃い、別役割の余白に差がある。

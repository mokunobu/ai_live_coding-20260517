# KNW-008 判断カード ブランドメタファー 木と知識

## 目的

KLGの社名に込められた「知識が木を育て、実りを収穫する」思想を、会社HPのデザインとコピーに一貫して使う。

## 核となる主張

KLGの木のモチーフは装飾ではなく、知識が広がり、育ち、成果になる構造として使う。

## 適用範囲

- トップページのコンセプト。
- ロゴ周辺の表現。
- サービス全体の図解。
- 研修、AI/DX、システム開発の共通メッセージ。

## 元ネタ

- [[../sources/SRC-008-社名とブランドストーリーユーザー発言|SRC-008]]
- [[../info/INF-009-KLG社名ブランドストーリー|INF-009]]

## 確認済み事実

- ユーザーは、社名に「知識が木を育て、木が育つと実りを収穫できる」というイメージを込めたと説明している。
- ユーザーは、樹形図のように知識が広がり、企業、社員、個人の木を育て、皆が収穫できて潤うという思いを説明している。

## 私の解釈

- 木のモチーフは、単なる葉や幹のイラストではなく、知識の蓄積、枝分かれ、成長、成果、循環の構造として使うと強い。
- KLGのサイトでは、AI/DXを「未来的な光」ではなく、「知識を業務と人に根付かせる支援」として表現できる。
- `根`, `幹`, `枝`, `葉`, `実` は装飾パーツではなく、情報設計とサービスプロセスへ対応させる。

## 再現手順

1. ブランド文脈を `根`, `幹`, `枝`, `葉`, `実` に分ける。
2. サービスを成長プロセスに対応させる。
3. ロゴの木と矛盾しない線、図形、余白を選ぶ。
4. 装飾として木を増やすのではなく、情報構造に組み込む。
5. `根=知識基盤`, `幹=伴走`, `枝=支援領域`, `実=成果` の対応が読めるか確認する。

## 判断基準

採用条件:
- KLGらしさを出したい。
- 会社思想をトップページや代表メッセージに反映したい。
- 知識管理、研修、AI/DX、システム開発を一つの思想で束ねたい。

不採用条件:
- 木の表現が幼く見える。
- 植物モチーフが強すぎてIT/DX企業の信頼感が弱くなる。

失敗条件:
- 葉や木の素材を置いただけで、事業との関係がない。
- 樹形図が複雑すぎて読めない。
- 「実り」「収穫」が成果保証のように見える。
- 緑色や植物素材だけが増え、知識の成長構造が伝わらない。

## AIへの指示 / 作業への使い方

```text
KLGのブランドメタファーは「知識が木を育て、企業・社員・個人に実りをもたらす」です。木を単なる装飾にせず、根=知識基盤、幹=伴走支援、枝=事業領域、実=成果として、情報構造や図解に反映してください。植物らしさを強くしすぎず、B2B/IT企業として知的で信頼できる表現にしてください。
```

## レビュー質問

- 木の表現は会社思想とつながっているか。
- IT/DX企業としての信頼感を損ねていないか。
- 樹形図や成長表現が、情報理解を助けているか。
- 根、幹、枝、実の対応がサービス説明と矛盾していないか。

## 検証 / 完了条件

- 木の表現が事業説明、導線、コピーのいずれかを助けている。
- 装飾だけの植物モチーフになっていない。

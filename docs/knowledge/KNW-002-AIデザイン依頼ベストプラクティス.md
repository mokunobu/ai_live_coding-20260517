# KNW-002 AIデザイン依頼ベストプラクティス

## 目的

AIに会社HPデザインを依頼するとき、AIっぽい汎用デザインを避け、B2B/IT企業として信頼できるデザインへ誘導する。

## 適用範囲

- AIへのWebサイトデザイン依頼。
- カンパニーサイトのデザインブリーフ。
- ワイヤーフレーム、ビジュアル方向性、実装指示。

## 元ネタ

- [[../sources/SRC-004-AIデザイン依頼と参照事例調査元|SRC-004 AIデザイン依頼と参照事例調査元]]
- サブエージェント調査結果。下流で重要判断に使うURLは直接確認する。

## 確認済み事実

- OpenAIは、明確で具体的な指示、文脈、出力形式、例示を使うプロンプト設計の重要性を案内している。
- W3CはWCAG 2.2を公開している。
- web.devはレスポンシブデザインとアクセシブルなレスポンシブ設計に関する情報を公開している。

## 私の解釈

- `かっこよく`、`モダンに` だけでは、青紫グラデーション、ガラスカード、抽象球体、AIっぽい3D表現に寄りやすい。
- AIには、情報設計、ブランドトーン、レイアウト、コンポーネント、画像方針、禁止表現、レスポンシブ、アクセシビリティ、実装制約をまとめて渡す必要がある。

## 推奨手順

AIへの依頼は、一発生成ではなく次の順で分ける。

1. 情報設計。
2. トーン・ブランド言語。
3. ワイヤーフレーム。
4. ビジュアル方向性。
5. セクション別デザイン。
6. レスポンシブ設計。
7. 実装制約に合わせた調整。
8. NG表現チェック。

## ブリーフ必須項目

- 誰に向けたサイトか。
- 訪問者の主目的。
- 情報の優先順位。
- ページ構成。
- ファーストビューで伝えること。
- ブランドトーン。
- 禁止するトーン。
- レイアウト原則。
- 必要コンポーネント。
- 画像・ビジュアル方針。
- レスポンシブ条件。
- アクセシビリティ条件。
- 実装制約。

## KLG向けブランドトーン

- 誠実。
- 知的。
- 実装力がある。
- 伴走型。
- 落ち着いた先進性。
- 派手なスタートアップ風ではなく、技術に強い実務パートナー。

## 禁止表現

- 過度な青紫グラデーション。
- ガラスモーフィズム多用。
- 意味のない3Dオブジェクト。
- 宇宙、脳、回路、発光ラインなどのAIテンプレ表現。
- 全面ダークテーマ。
- 抽象英語だけの見出し。
- 実態のない `革新`、`未来`、`変革` 連発。
- 読みにくい極細フォント。
- 装飾目的だけのアニメーション。
- CTAや本文を画像内テキストにする。

## AI依頼用プロンプト雛形

```text
株式会社ナレッジグローツリーのカンパニーサイト刷新案を作成してください。

目的:
AIっぽい汎用デザインを避け、実務的で信頼できるB2B/IT会社サイトにする。
対象は、DX・システム開発・業務改善を相談したい企業担当者、経営者、採用候補者。

ブランドトーン:
誠実、知的、実装力がある、伴走型、落ち着いた先進性。
派手なスタートアップ風ではなく、技術に強い実務パートナーとして見せる。

情報設計:
トップページには以下を含める。
1. ファーストビュー: 何を支援する会社か、誰に価値を出すか、CTA
2. 支援領域: DX支援、システム開発、AI活用、業務改善など
3. 選ばれる理由: 技術力、業務理解、伴走力
4. 実績/ケーススタディ
5. 支援プロセス
6. 会社情報
7. 採用またはチーム紹介
8. お問い合わせ

デザイン方針:
余白、タイポグラフィ、グリッド、実績情報で信頼感を出す。
色は白・黒・グレーを基調に、ブランドカラーをアクセントとして使う。
過度なグラデーション、ガラスカード、発光するAI風オブジェクト、宇宙・脳・回路の表現は禁止。

レイアウト:
12カラムグリッド。
カードを多用しすぎず、セクションごとに情報の役割を変える。
ファーストビューは大きな見出し、短い説明、CTA、実務感のあるビジュアルで構成する。

レスポンシブ:
375px、768px、1024px、1440pxで崩れない構成。
モバイルでは見出しが長すぎないよう調整する。

アクセシビリティ:
WCAG 2.2 AA相当を目安に、コントラスト、見出し階層、フォーカス状態、代替テキストを考慮する。

出力:
1. デザインコンセプト
2. トップページ構成
3. セクションごとのレイアウト説明
4. 色・タイポグラフィ方針
5. 使用するコンポーネント
6. 禁止した表現が入っていないかのセルフチェック
```

## 検証 / 完了条件

- AI出力が、事業内容より雰囲気を優先していない。
- `何の会社か` がファーストビューで分かる。
- 参照事例の流用範囲と禁止範囲が分かれている。
- モバイルとデスクトップのレイアウト条件がある。
- アクセシビリティ条件がある。
- 実装技術と更新方針に合っている。

## 使わない運用

- 参照サイトのビジュアルや構成を丸コピーしない。
- 事例サイトの実績や規模をKLGの事実として扱わない。
- AIの初回出力を最終デザインとして扱わない。

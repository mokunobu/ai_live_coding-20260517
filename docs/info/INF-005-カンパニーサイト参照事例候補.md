# INF-005 カンパニーサイト参照事例候補

## 目的

KLG会社HP刷新で、AIっぽい汎用デザインを避けるための参照候補を残す。

## 出典

- [[../sources/SRC-004-AIデザイン依頼と参照事例調査元|SRC-004 AIデザイン依頼と参照事例調査元]]

## 確認済み事実

このカード作成時点では、サブエージェントが参照候補として提示したURLを整理した。親スレッドでは各サイトの画面確認・スクリーンショット保存まではしていない。

## 私の解釈

- KLGでは、Awwwards系の派手さより、Land-book、Siteinspire、Lapa Ninja、Choicelyなどで実務寄りの近い事例を追加探索する方が合う。
- 参照候補は、デザインの見た目だけでなく、サービス説明、実績、問い合わせ、採用、会社情報の構成を確認してから絞る必要がある。

## 使用候補

- AIデザインブリーフ。
- 参照デザイン比較表。
- トップページワイヤー。
- 色・タイポグラフィ・グリッド方針。

## 再現手順

1. 各URLを直接開く。
2. PCとモバイルでファーストビュー、ナビ、事業紹介、実績、問い合わせ導線を確認する。
3. KLGに流用する要素と流用しない要素をスクリーンショット付きで整理する。
4. 最終参照は3-5件に絞る。

## エビデンス

- 現時点ではサブエージェント調査結果のみ。直接確認後に `docs/evidence/` へ追加する。

## 要確認 / 使わない運用

- 参照事例の実績、顧客、規模、数字をKLGの事実として扱わない。
- デザインギャラリー掲載情報だけで、現行サイトの状態を確認済みにしない。

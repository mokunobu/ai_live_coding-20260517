# INF-006 X起点デザイン収集候補

## 目的

KLG会社HP刷新で、Xに流れている有用なWebデザイン情報を見落とさないよう、追加収集する候補と使い方を整理する。

## 出典

- [[../sources/SRC-005-X起点デザイン情報補強参照元|SRC-005 X起点デザイン情報補強参照元]]

## 元ネタ

ユーザー指摘と追加Web検索。

## 確認済み事実

- 前回保存済みの `INF-005 カンパニーサイト参照事例候補` には、X起点の国内デザイン情報アカウントや投稿集約サイトが不足していた。
- `Recent Design` はX投稿からWeb、UI、インタラクションデザインを集めるサイトである。
- `Best Designs on X` はXに投稿されたデザインを集約するギャラリーとして複数サイトで紹介されている。
- `MUUUUU.ORG` はXリンクを持ち、制作者情報引用元としてX投稿を参照する事例がある。
- `デザインのこと`、`WebDesignClip` はXアカウントでもWebデザイン事例を流していることが検索結果で確認できる。

## 私の解釈

- KLGの参照収集では、Xを `最新事例の発見口` として使う価値がある。
- ただしX投稿は文脈が薄くなりやすいため、最終的には対象サイト本体、制作者情報、スマホ表示、問い合わせ導線を確認してから採用する。
- X由来の参考は、`見た目の雰囲気` だけでなく、`なぜKLGに合うか` をWRKに残す必要がある。

## 追加収集する候補

| 候補 | 役割 | KLGで見る観点 | 注意 |
| --- | --- | --- | --- |
| Best Designs on X | X投稿デザインの広域発見 | UI、モーション、タイポ、余白 | B2B会社サイトとは限らない |
| Recent Design | X由来のWeb/UI/インタラクション | 小さなUI表現、インタラクション | 古い投稿やプロダクトUIが混ざる |
| MUUUUU.ORG | 国内高品質Webサイト | 日本語企業サイト、制作者情報、カテゴリ検索 | 派手な演出をそのまま採用しない |
| 81-web | 国内Webデザイン | 日本語量、PC/SP、国内文脈 | KLG向け業種で絞る |
| SANKOU! | 国内Web/LP/企業サイト | IT/AI/コーポレート/誠実系の検索 | LP寄り表現と会社サイトを混ぜない |
| デザインのこと | 国内やさしいWebデザイン | 余白、やさしいトーン、SP表示 | KLGでは柔らかくしすぎない |
| WebDesignClip | 国内外のWebデザイン | 洗練された企業・採用・技術系サイト | 掲載理由を個別に確認する |
| 週刊ウェブデザイン | 大量のカテゴリ別リンク | 企業・法人、デジタル・通信 | 質の選別が必要 |

## KLG向け収集条件

優先する:

- B2B / IT / DX / AI / 開発会社に近い。
- 日本語の文章量がある。
- 会社情報、事業内容、問い合わせ導線が見つけやすい。
- AIっぽい青紫グラデーション、発光球体、回路表現に頼っていない。
- モバイルで見出しとCTAが読みやすい。
- 実績やプロセスを見せる構成がある。

避ける:

- 作品性が高すぎて会社HPとして情報が探しにくい。
- スクロール演出や動画に依存している。
- 採用・ブランドサイト寄りで、事業相談導線が弱い。
- コピーが抽象的で、何をしている会社か分からない。

## 使用候補

- 次の参照事例選定WRK。
- AIデザインブリーフ。
- トップページ構成の調整。
- 色、余白、タイポグラフィ、図解の方向性決定。

## 再現手順

1. 各候補サイトでKLG向け条件に合うサイトを10件程度拾う。
2. PC/SPのスクリーンショットを保存する。
3. `流用してよい要素` と `流用してはいけない要素` を分ける。
4. 最終参照を3-5件に絞る。
5. `WRK` に比較表として残す。

## エビデンス

- 個別候補のスクリーンショットは未保存。

## 要確認 / 使わない運用

- このカードは候補リストであり、まだ採用参照ではない。
- X投稿やギャラリー掲載を、対象サイトの品質保証として扱わない。
- 下流で使う前に、対象サイト本体を直接確認する。

# INF-003 現行事業領域

## 目的

会社HP刷新時に、現行サイトで掲載されている事業領域を漏らさず再整理できるようにする。

## 出典

- [[../sources/SRC-001-現行Google-Sites会社HP|SRC-001 現行Google Sites会社HP]]

## 元ネタ

現行HPのトップ、事業内容、各事業ページ。

## 確認済み事実

現行HPの事業領域は次の4つ。

- システム開発事業
- インフラ構築事業
- IT人材研修支援事業
- テレワーク・配信支援

トップページでは、別枠で次の訴求も掲載されている。

- DX推進支援
- AI導入利活用支援

## 私の解釈

- `DX推進支援` と `AI導入利活用支援` は、個別事業というより、4事業を横断する上位テーマとして整理できる可能性がある。
- 会社HP一新では、4事業を単なる一覧にせず、相談者の課題別に入口を作る方が使いやすい。

## 使用候補

- トップページの事業概要。
- サービス一覧。
- サービス詳細ページ。
- 問い合わせ前の相談テーマ分類。

## 再現手順

- `home.txt` と `business.txt` を確認する。
- 各事業ページの見出しと本文を照合する。

## 要確認 / 使わない運用

- `DX推進支援` と `AI導入利活用支援` を正式な事業名として扱うかは未確認。
- 実績、対応技術、対応範囲、料金、契約形態は現行HPだけでは不足している。

# INF-015 ダサいキャッチコピー原因分析

## 目的

Stitch初稿のコピーが「AIっぽい」「ダサい」「心が動かない」と感じられる原因を、修正可能な情報へ分解する。

## 元ネタ

- [[../sources/SRC-015-キャッチコピーとB2B価値提案参照元|SRC-015]]

## 確認済み事実

- 良い価値提案は、提供内容、対象者、便益、差異を短時間で理解できる必要がある。
- B2B企業のコピーは、事業内容が複雑で自分ごと化されにくい。
- 曖昧、過剰、専門的すぎるコピーは、理解や信頼を下げる。
- キャッチコピーは、目的、ターゲット、訴求ポイントを決めてから表現を作る必要がある。
- 競合でも使える抽象語は独自性を作らない。
- AIっぽい文章には、機械的な箇条書き、誇張表現、英語的なコロン構造、説明過多、抽象語の反復が出やすい。

## 私の解釈

- Stitch初稿の `知識を育て、業務に根づかせるAI/DX支援` は、KLGの思想には沿っているが、誰のどんな痛みをどう変えるのかが弱い。
- `AI/DX導入、業務システム開発、IT基盤整備、IT人材育成` を並べるだけだと、守備範囲の羅列になり、相談者の切実さに接続しない。
- `技術パートナー`, `伴走`, `定着`, `成果` は便利だが、使い古されており、具体化しないとAIっぽく見える。
- 木のメタファーは、見せ方を間違えると「きれいごと」「教育系のふんわり感」に寄る。

## ダサく見える主因

1. 主語が相談者ではなく会社/概念になっている。
2. 課題が抽象的で、読者が「自分の話だ」と思えない。
3. 提供価値が広すぎて、何を頼める会社か絞れていない。
4. `育てる`, `根づく`, `収穫する` が比喩だけで終わり、現場の変化に接続していない。
5. 成果を言いたいが、実績や数字が未確認なので言い切れず、結果として弱い一般論になっている。
6. 文がきれいにまとまりすぎて、切実さ、違和感、引っかかりがない。
7. B2Bサイトとして、決裁者、現場担当者、研修担当者のどれに向けた言葉か分からない。

## 補うべき情報

- KLGが最も得意な相談パターン。
- 相談者が最初に言う生の言葉。
- 相談前の困りごと。
- 相談後にどう変わるか。
- KLGらしい言い回し、避けたい言い回し。
- 公開できる実績、対応範囲、使える固有名詞。
- 現場に刺さる痛み: 属人化、AI導入だけ進んで業務に乗らない、研修が実務に残らない、ツールが増えて使われない、要件が言葉にならない。

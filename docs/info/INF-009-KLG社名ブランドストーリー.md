# INF-009 KLG社名ブランドストーリー

## 目的

株式会社ナレッジグローツリーの社名に込められた意味を、会社HPのコンセプト、コピー、ビジュアル、情報設計に使えるように整理する。

## 出典

- [[../sources/SRC-008-社名とブランドストーリーユーザー発言|SRC-008 社名とブランドストーリー ユーザー発言]]

## 元ネタ

- ユーザー発言: `knowledge grow tree / ナレッジグローツリー` はユーザーが作った社名。
- ユーザー発言: 知識が木を育て、木が育つと実りを収穫できるというイメージ。
- ユーザー発言: 樹形図のように知識を広げ、企業、社員、個人の木を育て、皆が収穫できて潤うようにするという思い。

## 確認済み事実

- ユーザーは社名の由来と思想を上記のように説明している。
- ユーザーはロゴに木が入っていると説明している。
- このカード作成時点では、ロゴ画像そのものは未確認。

## 私の解釈

- ブランドの中心語は、`知識`, `育つ`, `枝分かれ`, `樹形図`, `実り`, `収穫`, `潤う`, `企業`, `社員`, `個人`。
- サイト全体のコンセプトは、`知識を蓄える会社` ではなく `知識を育てて、使える成果にする会社` と表現する方が社名意図に合う。
- ビジュアルは、木そのもののイラストだけでなく、枝分かれする情報構造、成長する年輪、根から幹、枝、実へ進むプロセス図として展開できる。

## 使用候補

- トップページのコンセプトコピー。
- 代表メッセージ。
- ロゴ周辺の説明。
- サービス導線の図解。
- AI/DX支援、研修支援の共通ブランドメッセージ。
- デザイン判断カード `KNW-008`。

## 再現手順

1. ユーザー発言を確認する。
2. 会社HPのコピーに使う場合は、公開してよい表現か確認する。
3. ロゴ原本を確認し、木の表現をどこまでビジュアル展開できるか判断する。
4. 事業説明へつなげる場合は、各事業が「知識を育てる」プロセスのどこに当たるか整理する。

## 要確認 / 使わない運用

- 公開コピーとして使う前に、代表メッセージとして出すか、サイト全体の裏テーマに留めるか確認する。
- 木の装飾を多用しすぎて、IT/DX企業としての信頼性を弱めない。
- `Knowledge Grow Tree` の英語表記、略称、ロゴデータを確認する。

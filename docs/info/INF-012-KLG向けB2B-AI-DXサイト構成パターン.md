# INF-012 KLG向けB2B AI DXサイト構成パターン

## 目的

近い領域のB2B/AI/DX/研修サイトから、KLGの会社HP構成に使えそうな型を抽出する。

## 元ネタ

- [[../sources/SRC-012-B2B-AI-DX研修支援サイト参照元|SRC-012]]
- [[../sources/SRC-008-社名とブランドストーリーユーザー発言|SRC-008]]

## 確認済み事実

- Saixは、戦略、教育、実装の3領域と、Assess、Design、Deliverの3段階を提示している。
- DXAIは、生成AIによるDX支援として、研修、導入支援、PoC、ガバナンス、実装、ルールメイキングなどを提示している。
- Generative Agentsは、教育・研修、開発支援、人材支援、プロダクトをナビゲーションに持つ。
- キカガクは、DX・AI人材育成で、人材育成計画、アセスメント、eラーニング、カスタマイズ研修、PBL、AX推進支援を提示している。
- ユーザーはKLGの社名について、知識が木を育て、企業・社員・個人が収穫できるイメージを説明している。

## 私の解釈

- KLGの会社HPは、単なるサービス一覧よりも、知識が育ち、業務に根づき、成果になるプロセスとして見せる方が社名思想と合う。
- 構成候補は `課題診断 -> 知識整理 -> 研修/伴走 -> 実装 -> 定着 -> 成果の収穫`。
- AI/DX支援は範囲が広く見えやすいので、KLGが実際に支援できる範囲と、相談導線を明確にする必要がある。

## 要確認

- KLGの正式なサービス範囲、提供実績、掲載可能な事例。
- 「成果」「収穫」の表現が成果保証に見えないコピー設計。

## 使わない運用

- 他社の実績数値、顧客ロゴ、導入企業数をKLGの事実として使わない。
- 研修、開発、コンサル、顧問、PoCを全部できるように見せる前に、実対応範囲を確認する。

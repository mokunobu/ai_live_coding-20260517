# INF-008 良いWebデザイン判断軸

## 目的

良いWebサイトを評価する観点を、会社HP刷新とAIデザイン依頼に使える形で整理する。

## 出典

- [[../sources/SRC-007-Webデザイン評価原則参照元|SRC-007 Webデザイン評価原則参照元]]

## 元ネタ

- NN/gのユーザビリティ原則、視覚デザイン原則。
- W3C WCAG 2.2。
- GOV.UKのデザイン原則。
- MUUUUU.ORGの掲載基準。
- SANKOU!、MUUUUU.ORG、Recent Designのカテゴリ・掲載情報。

## 確認済み事実

- 良い視覚デザインの基本軸として、スケール、視覚階層、バランス、コントラスト、ゲシュタルトが挙げられている。
- ユーザビリティ評価では、状態の可視性、現実世界との一致、制御、一貫性、エラー予防、記憶負荷低減、柔軟性、最小限の設計、エラー回復、ヘルプが重要視されている。
- アクセシビリティでは、テキストと背景のコントラストを数値で確認する基準がある。
- GOV.UKは、ユーザーニーズ、データ、シンプル化、反復、全員に向けた設計、利用文脈、サービス視点を重視している。
- MUUUUU.ORGは、企業サイトや採用サイトのような実務条件下で、レイアウト整合性、情報階層、ユーザー導線、コンテンツとビジュアルのバランス、下層ページ、PC/SP、制約の中の工夫を見ている。

## 私の解釈

- KLGの会社HPで使うべき判断軸は、目的、情報階層、内容量、構造、視覚、ブランド、実装の順がよい。
- 良いサイトは、単に格好よいのではなく、誰に何を伝え、次に何をしてもらうかが明確である。
- KLGでは、知識、成長、樹形図、収穫のメタファーが、装飾ではなく会社の思想として伝わるかも評価軸に入る。

## 使用候補

- 参照サイトの評価。
- AI生成デザインの採点。
- デザインブリーフ。
- KLGトップページの構成レビュー。
- 公開前チェックリスト。

## 再現手順

1. 対象サイトやAI出力を見る。
2. 見た目の印象を先に結論にせず、目的、情報階層、導線、視覚、ブランド、実装の順に確認する。
3. 使える要素を `KNW` 判断カードへ分解する。
4. KLG向けに採用、保留、不採用を分ける。

## 要確認 / 使わない運用

- ギャラリー掲載サイトを、そのままKLGに合う事例として扱わない。
- 見た目だけで良し悪しを判断しない。
- デザイン原則をすべて同じ強さで適用しない。KLGの目的とターゲットに合わせて優先順位を決める。

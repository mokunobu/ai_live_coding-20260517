# Info MOC

抽出情報カードの入口。

## ルール

- `INF` は元ネタから抽出した使える可能性のある情報を管理する。
- 採用、不採用、IA位置、優先度はここでは固定しない。
- 事実、解釈、使用候補、要確認を分ける。
- 必ず参照元SRCへ戻れるようにする。

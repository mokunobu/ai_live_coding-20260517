# Use MOC

作業目的別に、どのSRC / INF / KNW / WRKを見るかを示す入口。

`Use MOC` はWisdom相当の地図として使う。ただし、ここ自体を元ネタや結論の正本にしない。

## 使い方

- 新しい作業パターンができたら、ここに「開始時に見るカード」を追加する。
- 調査、設計、実装、レビュー、報告など、目的別に入口を作る。
- 判断根拠を書く場合は、該当するSRC / INF / KNW / WRKへリンクする。

使い方:

- ルート `DESIGN.md` を正本にする。
- `DESIGN.md` が品質ゲートを満たすか確認してからStitchへ渡す。
- Stitch MCPの一部RPC失敗だけで接続断と判断しない。
- `upload_design_md -> create_design_system_from_design_md` を優先する。
- Stitch出力は `get_project -> list_screens -> get_screen` でMCP経由取得する。
- Stitch出力は判断カードでレビューしてから採用する。

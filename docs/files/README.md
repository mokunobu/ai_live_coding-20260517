# Files

`files/` は元ファイル、受領素材、PDF、画像、動画、外部から保存した資料を置く。

## ルール

- ファイルを置いたら、対応するSRCまたはWRKから参照する。
- `files/` 内の素材を成果物から直接参照しない。
- 加工、採用、公開利用する場合は、WRKで判断と使用範囲を記録する。
- ファイル名だけで意味を判断しない。カード側に目的、元ネタ、使用範囲を書く。

## 使わない運用

- `files/` に置いたことだけを証拠成立にしない。
- 整理文書や成果物を元ネタとして扱わない。

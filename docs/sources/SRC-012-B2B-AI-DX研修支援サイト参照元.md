# SRC-012 B2B AI DX研修支援サイト参照元

## 目的

KLGのAI/DX支援、IT人材研修、実装支援を会社HPで整理するため、近い領域のB2Bサイト構成を参照する。

## 元ネタ

- Generative Agents: `https://generative-agents.co.jp/`
- Saix: `https://saixtech.com/`
- DXAI: `https://dx-ai.jp/`
- i3DESIGN: `https://www.i3design.jp/`
- キカガク DX・AI人材育成: `https://www.kikagaku.co.jp/business/training`
- Retool: `https://retool.com/`
- Linear: `https://linear.app/`
- Cloudflare: `https://www.cloudflare.com/`
- Vercel: `https://vercel.com/`

## 確認済み事実

- Generative Agentsは、教育・研修、開発支援、人材支援、プロダクトをナビゲーションに持ち、AIエージェントの種類とサービスマップを示している。
- Saixは、生成AI研修・AI人材育成、生成AI顧問・AIコンサルティング、業務AI化・自動化の実装支援をサービスに持ち、戦略、教育、実装の3領域を提示している。
- Saixは、Assess、Design、Deliverの3段階で、経営課題の診断、戦略と実装の設計、実装・定着と成果創出を説明している。
- DXAIは、生成AIによるDXをあらゆるフェーズでサポートすると訴求し、研修・教育、生成AI導入支援、PoC、ガバナンス構築、実装、ルールメイキング等を提示している。
- i3DESIGNは、Design × AI × Engineeringで日本のITを再起動するというメッセージを掲げ、AI駆動開発支援、デザインシステム構築支援、UX/UI改善などをサービスに持つ。
- キカガクは、DX・AI人材育成で、人材育成計画策定、DXアセスメント・eラーニング、カスタマイズ研修、実データPBL研修、AX推進支援を提示している。
- キカガクは、資料請求とアセスメント無料体験の導線を持つ。
- Retool、Linear、Cloudflare、Vercelは、B2B/Tech企業サイトとして、プロダクト、用途、信頼材料、CTAを組み合わせる参照候補である。

## 私の解釈

- KLGに近い構成は、単発サービス一覧ではなく、`知識を育てる -> 業務へ根付かせる -> 仕組み化する -> 定着する -> 成果を収穫する` という成長プロセスで見せる形。
- AI/DX支援は、研修、導入相談、PoC、実装、運用定着、ガバナンスのどこまで支援できるかを明確にする必要がある。

## 再現手順

1. 各URLを開く。
2. サービス分類、CTA、事例、プロセス、信頼材料を抽出する。
3. KLGに流用できる構成と、KLGの事実として使えない実績・数値を分ける。

## 確認済み事実

- NN/gは、視覚デザインの原則としてスケール、視覚階層、バランス、コントラスト、ゲシュタルトを整理している。
- NN/gのユーザビリティヒューリスティックは、システム状態の可視性、現実世界との一致、ユーザー制御、一貫性、エラー予防、記憶負荷の低減、柔軟性、審美的で最小限の設計、エラー回復、ヘルプを含む。
- W3C WCAG 2.2は、通常テキストのコントラスト比 4.5:1 以上、大きな文字の 3:1 以上をAA基準の目安として説明している。
- GOV.UKのデザイン原則は、ユーザーニーズから始める、データで設計する、難しいことをシンプルにする、反復する、全員のために作る、文脈を理解する、サービスとして考えるなどを含む。
- MUUUUU.ORGは、企業サイトや採用サイトのような実務条件下で、レイアウト整合性、情報階層、導線設計、コンテンツとビジュアルのバランス、下層ページ、PC/SP、制約の中での工夫も見ると説明している。
- SANKOU!とMUUUUU.ORGは、業種、サイトタイプ、配色、テイスト、動きなどで参照サイトを絞り込める。
- Recent Designは、X上のWeb/UI/インタラクションデザイン事例を収集している。

## 私の解釈

- 良いデザインは「見た目が新しい」だけではなく、目的、対象者、情報階層、操作導線、読みやすさ、制約への応答、ブランドらしさが揃っている状態として扱うべき。
- カンパニーサイトでは、派手な表現よりも、会社が何をしていて、誰の課題を解決し、どう信頼できるかが伝わることを優先する。
- AIに渡すデザイン知識は、原則名だけでなく、採用条件、失敗条件、レビュー質問、KLGへの適用案に分解すると使いやすい。

# SRC-005 X起点デザイン情報補強参照元

## 目的

会社HP刷新のデザイン参照として、Xで流れてくる有用なWebデザイン情報、X投稿を集約するギャラリー、国内Webデザイン更新アカウントを補強対象として残す。

## 元ネタ

ユーザー指摘:

> Xに有用なデザイン情報流してくれてるところあったよね？そういうのみてないの？

## 確認した参照URL

### X投稿集約・X起点ギャラリー

- Best Designs on X: `https://bestdesignsonx.com/`
- Fountn紹介ページ: `https://fountn.design/resource/best-designs-on-x/`
- DesignToolMark紹介ページ: `https://designtoolmark.com/resources/detail/best-designs-on-x-com`
- Recent Design: `https://recent.design/`

### 国内Webデザインギャラリー / X連携

- MUUUUU.ORG: `https://muuuuu.org/`
- 81-web About: `https://81-web.com/about/`
- SANKOU!: `https://sankoudesign.com/`
- デザインのこと: `https://designnokoto.com/_____wd_`
- WebDesignClip: `https://webdesignclip.com/`
- 週刊ウェブデザイン: `https://www.dailywebdesign.com/`

### Xアカウント候補

- デザインのこと: `https://x.com/designnokoto`
- WebDesignClip: `https://x.com/webdesignclip`
- mami tanii / tote_webdesign: `https://x.com/ToteWebdesign`
- MUUUUU.ORG X: `https://x.com/muuuuu_org` またはMUUUUU.ORGサイト上のXリンクから確認する。

## 確認済み事実

- Recent Designは、Xに投稿されたWeb、UI、インタラクションデザインを集めるサイトとして `The best of recent web, interface and interaction design on X` と説明している。
- MUUUUU.ORGは、Xリンクを持ち、サイト内で `制作者情報引用元` としてX投稿URLを掲載している事例がある。
- MUUUUU.ORGは、`コーポレートサイト・企業サイト`、`コンピュータ・テクノロジー`、`制作・開発・企画・マーケティング・コンサル`、`スタイリッシュ`、`グリッド`、`洗練されたタイポグラフィ・文字組み` などの絞り込みを持つ。
- 81-webは、日本国内のサイトのみを厳選して掲載し、Twitter / X、Facebook、はてなブックマーク等の反応を扱ってきたと説明している。
- SANKOU!は、国内Webデザインのギャラリーで、`Web･IT･AI･デジタル･テクノロジー･通信`、`コーポレートサイト`、`誠実･信頼感`、`スタイリッシュ` などの絞り込み候補を持つ。
- デザインのことは、Webデザインギャラリーとして `企業サイト`、`レスポンシブ`、`Webフォント`、`写真` などの分類を持つ。

## 私の解釈

- 前回の調査は、海外寄りのギャラリーと一般的なベストプラクティスに偏っており、Xで流れる国内外の最新制作事例や制作者投稿の探索が不足していた。
- KLGのデザイン参照では、Awwwards系の派手な表現より、国内ギャラリーとX投稿の制作者情報を使い、`日本語量`、`会社情報の見せ方`、`IT企業らしさ`、`AIっぽくない先進性` を確認した方がよい。

## 再現手順

1. MUUUUU.ORGで `コーポレートサイト・企業サイト`、`コンピュータ・テクノロジー`、`制作・開発・企画・マーケティング・コンサル`、`スタイリッシュ`、`グリッド`、`洗練されたタイポグラフィ・文字組み` を中心に検索する。
2. SANKOU!で `Web･IT･AI･デジタル･テクノロジー･通信`、`コーポレートサイト`、`誠実･信頼感`、`スタイリッシュ`、`シンプル` を中心に検索する。
3. 81-web、デザインのこと、WebDesignClipで企業サイト、IT/デジタル系、制作会社系を確認する。
4. XアカウントやX投稿は、スクリーンショットまたはURL付きで保存し、投稿者、投稿日、対象サイト、参照したい要素を分ける。
5. KLGに合う候補だけ、`INF` または `WRK` に昇格する。

## 要確認 / 使わない運用

- X投稿は流れやすく、削除・非公開・文脈欠落が起きるため、重要参照はスクリーンショットまたは保存HTMLを残す。
- Xの投稿者が書いた制作実績や数値を、KLGの事実として扱わない。
- ギャラリー掲載サイトの見た目だけを真似しない。会社情報、事業説明、問い合わせ導線、モバイル表示まで確認する。

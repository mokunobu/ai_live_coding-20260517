# SRC-008 社名とブランドストーリー ユーザー発言

## 目的

株式会社ナレッジグローツリーの社名、ロゴ、ブランドストーリーの意図を、会社HP刷新とデザイン判断の元ネタとして保存する。

## 元ネタ

- 種別: ユーザー発言
- 取得元: このスレッド
- 取得日時: 2026-05-17T08:02:11+0900

## ユーザー発言

> knowledge grow tree
> ナレッジグローツリー
> が私の作った社名になります。
> 知識は木を育てる
> 木を育てれば身がなって収穫できる
> といったイメージでしたなのでロゴにも木が入っています。
>
> 樹形図のようなイメージでどんどんと知識を広げて企業や社員や個人の木を育てていけば
> 皆が収穫できて潤うようになる
> そういう思いを持って作った会社です。

## 確認済み事実

- ユーザーは `knowledge grow tree / ナレッジグローツリー` を自身が作った社名だと説明している。
- ユーザーは、社名に「知識が木を育て、木が育つと実りを収穫できる」というイメージを込めたと説明している。
- ユーザーは、ロゴにも木が入っていると説明している。
- ユーザーは、樹形図のように知識が広がり、企業、社員、個人の木を育て、皆が収穫できて潤う状態を会社の思いとして説明している。

## 私の解釈

- KLGのブランドの核は、単なるIT支援ではなく「知識を育て、使える成果へ変える」ことにある。
- 木のモチーフは装飾ではなく、情報設計、成長、蓄積、枝分かれ、収穫、循環を表す中心メタファーとして使える。
- AI/DX支援の表現も、未来感や派手さより、知識が整理されて使える形になり、事業や人に実りが出るという文脈へ接続できる。

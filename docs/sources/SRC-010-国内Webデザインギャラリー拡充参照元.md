# SRC-010 国内Webデザインギャラリー拡充参照元

## 目的

KLG会社HP刷新で、国内の企業サイト、IT/DX/教育/研修サイト、誠実で読みやすいデザインを探す入口を管理する。

## 元ネタ

- MUUUUU.ORG 掲載基準: `https://muuuuu.org/about`
- SANKOU!: `https://sankoudesign.com/`
- 81-web Feature: `https://81-web.com/feature/`
- WebDesignClip: `https://webdesignclip.com/`
- デザインのこと: `https://designnokoto.com/`
- I/O 3000 About: `https://io3000.com/about/`
- I/O 3000 Category: `https://io3000.com/category/bm/`

## 確認済み事実

- MUUUUU.ORGは、企業サイトや採用サイトなど実務条件下のWebサイトを紹介し、レイアウト整合性、情報階層、導線、コンテンツとビジュアルのバランスを見ると説明している。
- MUUUUU.ORGは、ファーストビューだけでなく下層ページ、PC/SP、コンテンツ量、制約下の工夫を見ると説明している。
- SANKOU!には、Web・IT・AI・デジタル・テクノロジー・通信、制作・開発・企画・マーケティング・コンサル、学校・教育、スクール・習い事・教材などの業種分類がある。
- SANKOU!には、誠実・信頼感、日本語主体・英語少なめ、ステキなインフォグラフィックあり、花・木・葉・植物を使用などの特徴分類がある。
- 81-webは、約5,000件以上の掲載サイトから、Keyword、タイプ、カテゴリ、カラー、フォント、タグ、制作会社、掲載日時でAND検索できると説明している。
- WebDesignClipは、6,192件掲載と表示し、企業サイト・事務所・ビジネス、学校・教育、React/Next.js、Astro、Studioなどの分類を表示している。
- デザインのことは、all 4000デザイン、PC 2002、SP 1998と表示し、シンプル、やさしい、しっかり、企業サイト、学校・教育などの分類を持つ。
- I/O 3000は、国内外問わずWeb制作の参考となるサイトをセレクトすると説明している。

## 私の解釈

- KLGでは、国内ギャラリーを「見た目探し」ではなく、検索条件を固定して比較するために使う。
- 特に、`企業サイト`, `Web・IT・AI`, `制作・開発・コンサル`, `学校・教育`, `誠実・信頼感`, `日本語主体`, `インフォグラフィック`, `植物` を探索軸にする。

## 再現手順

1. 上記ギャラリーを開く。
2. KLG向け検索条件を固定する。
3. 候補サイトURLを個別に開く。
4. ギャラリー掲載ページだけでなく、実サイトのPC/SPと下層ページを確認する。

## 要確認 / 使わない運用

- ギャラリーの掲載は品質保証ではない。
- 掲載スクリーンショットやコピーは流用しない。
- 実例サイトを採用候補にする前に、実サイトURLとスクリーンショットを保存する。

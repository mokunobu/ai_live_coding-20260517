# SRC-016 キャッチコピー認知心理と言語科学参照元

## 目的

KLGサイトのキャッチコピーを、思いつきや言葉遊びではなく、読者の認知、記憶、理解、行動判断に接続して設計するための元ネタを管理する。

## 元ネタ

- Reber, Schwarz, Winkielman, Processing Fluency and Aesthetic Pleasure: `https://tiffaning.com/files/Reber%20et%20al_2004_Processing%20fluency%20and%20aesthetic%20pleasure.pdf`
- Rogers, Kuiper, Kirker, Self-Reference and the Encoding of Personal Information: `https://peda.net/p/Markus%20Lajunen/pmp3/internal-assessment/fofia/sateopi%3Afile/download/1bff3ea36308a106de9e04b54e83bd1de3e24805/Rogers1977.pdf`
- Packard, Berger, How Concrete Language Shapes Customer Satisfaction: `https://academic.oup.com/jcr/article/47/5/787/5873524`
- Wiswede et al., Memory recall in arousing situations: an emotional von Restorff effect?: `https://link.springer.com/article/10.1186/1471-2202-7-57`
- Kahneman, Tversky, Prospect Theory: An Analysis of Decision under Risk: `https://web.mit.edu/curhan/www/docs/Articles/15341_Readings/Behavioral_Decision_Theory/Kahneman_Tversky_1979_Prospect_theory.pdf`
- CXL, How to Create a Unique Value Proposition: `https://cxl.com/blog/value-proposition-examples-how-to-create/`
- Baymard, What Is UX Writing, and What Do UX Writers Do?: `https://baymard.com/learn/ux-writing`
- 宣伝会議, BtoB企業のコピーを書くための10箇条: `https://www.sendenkaigi.com/marketing/media/sendenkaigi/027585/`
- 日本政策金融公庫, 「欲しい！」と思わせる販促ツールの戦略: `https://www.jfc.go.jp/k/pfcj/pdf/uru_141126.pdf`

## 確認済み事実

- Reberらは、対象を処理しやすいほど肯定的な美的反応が生じやすいという処理流暢性の枠組みを提示している。処理しやすさには、形、コントラスト、反復、意味的な準備などが関わる。
- Rogersらは、構造的処理、音韻的処理、意味的処理、自己参照処理を比較し、自己参照で評価した語の想起が最も高いという結果を示している。
- Packard and Bergerは、顧客対応の実データと実験を使い、具体的な言葉は「相手が自分の状況を理解している」という知覚を高め、満足や購買意向に影響すると説明している。
- Wiswedeらは、リスト内で他と異なる項目は想起されやすいというvon Restorff効果に触れ、色で区別された語の想起が標準条件より高かったと報告している。
- Kahneman and Tverskyは、意思決定では最終状態ではなく利得と損失の変化として価値が評価されやすく、同じ選択肢でも提示のされ方が選好に影響することを示している。
- CXLは、価値提案には関連性、具体的な価値、差別化が必要であり、読者が約5秒で理解できる明確さを重視している。
- Baymardは、UXライティングはユーザーの行動を助ける言葉であり、悪い文章は混乱や離脱につながると説明している。
- 宣伝会議は、BtoB企業のコピーが難しい理由として、事業や製品を自分ごとにしにくいことを挙げ、パーパスの把握、価値の集約、例える視点を示している。
- 日本政策金融公庫の資料は、商品やサービスを知っただけで欲しいと思う人はほとんどおらず、興味、理解、不安解消、行動意欲の変化を導く必要があると説明している。

## 注意点

- 心理学の知見は、KLGサイトで必ず同じ効果を生む保証ではない。
- 損失回避やフレーミングを、読者を煽るために使わない。B2Bでは不安を強くしすぎると信頼を落とす。
- 処理流暢性は「平凡にする」ことではない。読みやすさと、競合に埋もれない違いを両立させる必要がある。
- 記憶に残すための違いは、見た目の奇抜さではなく、意味上の違いとして設計する。会社サイトでは、読者の業務上の違和感を短く置く方が安全。
- 具体語は有効だが、対象顧客の実際の言葉を確認しないまま作ると、具体的に見えるだけの作り話になる。

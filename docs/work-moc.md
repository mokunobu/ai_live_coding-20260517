# Work MOC

作業、判断、検証、成果物管理カードの入口。

## ルール

- `WRK` は作業記録であり、元ネタではない。
- 入力、手順、判断、成果物、検証、未完了事項を書く。
- 成果物へ反映する事実は、WRKではなくSRC / INFへ戻って確認する。

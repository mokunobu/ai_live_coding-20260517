# Source MOC

出典カードの入口。

## ルール

- `SRC` は元ネタの所在、確認日時、証跡、注意点を管理する。
- 出典IDは日本語名とセットで書く。
- 整理文書、作業成果物、AI要約を元ネタそのものとして扱わない。
- 外部ページ、価格、規約、仕様、ニュースなど変わる情報は `source_observed_at` を時刻まで残す。

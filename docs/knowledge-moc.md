# Knowledge MOC

再利用できる判断基準、手順、型の入口。

## ルール

- `KNW` は案件固有の事実根拠ではない。
- 適用範囲、再現手順、判断基準、検証条件、禁止運用を書く。
- 抽象論だけを保存しない。元ネタ、証跡、実例、失敗条件へ戻れるようにする。
- `scope/global`, `scope/domain`, `scope/local` のどれかで、知識の適用範囲を切り離せるようにする。

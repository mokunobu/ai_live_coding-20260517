# Evidence

`evidence/` はスクリーンショット、保存HTML、コマンドログ、検証出力、比較画像などの証跡を置く。

## ルール

- 証跡を保存したら、対応するSRC、INF、KNW、WRKから参照する。
- `evidence_captured_at` をカードに明示する。
- 何が写っていれば証拠成立かをカードに書く。
- どの判断に使う証跡かをカードに書く。

## 使わない運用

- `スクリーンショットを保存した` だけで証拠成立にしない。
- 一時テスト画像、途中ログ、確認不能な画像を最終証跡として扱わない。
- 証跡から直接確認できないことを確認済み事実にしない。

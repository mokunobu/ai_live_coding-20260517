## 確認済み事実

- Cloudflare Pagesの静的Next.js向け設定は、`Next.js (Static HTML Export)`、ビルド出力先 `out` で運用できる。
- Next.jsの静的エクスポートは `next.config` に `output: 'export'` を指定し、`next build` 後に `out` を生成する。
- Stitch出力HTMLでは、会社情報の「設立」行に所在地の文言が残っていた。

## 私の解釈

- Stitch HTMLは正本ではなく、構成、余白、視覚階層、トーンの参照素材として扱う。
- 会社情報はReact側で配列化し、確認済みの表記だけを表示する。
- Cloudflare Pagesに置く前提では、フォーム送信やサーバー処理は未実装のまま明示的に無効化する。

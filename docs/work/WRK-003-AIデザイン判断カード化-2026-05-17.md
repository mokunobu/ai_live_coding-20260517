# WRK-003 AIデザイン判断カード化 2026-05-17

## 目的

ユーザーの「良いデザイン情報を収集して、カードにバラして、AIに使えるようにしたい」という依頼に対し、Zettelkastenの分解ルールを補強し、初期の判断カードセットを作る。

## 前提

- 前回までの収集は、参照元候補と会社HP構成案が中心だった。
- ユーザーは、AIデザインが微妙になる理由として、AIが良いデザインを判断する材料を持っていないのではないかと仮説を出した。
- ユーザーは、KLGの社名に込めた「知識が木を育て、実りを収穫する」思想を説明した。
- 既存の `card-system.md` にはZettelkastenの分解粒度が不足していたため、先にルールを補強した。

## 手順

- 既存ルールに「Zettelkasten分解ルール」を追加した。
- `KNW` テンプレートに「核となる主張」「AIへの指示 / 作業への使い方」「レビュー質問」を追加した。
- AIデザインの失敗要因に関する記事をSRC化した。
- Webデザインの評価原則、アクセシビリティ、ギャラリーの掲載基準をSRC化した。
- ユーザー発言をブランドストーリーの元ネタとしてSRC化した。
- 使い回せる判断単位に分解し、初期KNWを作成した。

## 判断

採用したこと:
- AIデザインの問題を「AIがデザインを知らない」と断定せず、「判断基準、文脈、制約の不足」として整理する。
- デザイン情報は、参照サイト単位ではなく、余白、階層、可読性、コントラスト、ブランドメタファー、AIっぽさ回避の判断カードへ分解する。
- KLGの木のメタファーを装飾ではなく、情報構造と成長プロセスとして扱う。

採用しなかったこと:
- 参照サイトのデザインをそのままKLGに当てはめる。
- AI批判記事の表現をそのまま結論として使う。
- Xやギャラリーの収集を完了扱いにする。

# WRK-004 デザイン元ネタ追加調査とカード化 2026-05-17

## 目的

KLG会社HP刷新に向け、元ネタを増やし、Zettelkastenの分解ルールに沿って `SRC -> INF -> KNW` へカード化する。

## 入力

- ユーザー指示: X起点のデザイン情報、AIデザインが微妙になる理由、良いデザイン判断、カード化の不足指摘。
- ユーザー発言: KLGの社名とブランドストーリー。
- サブエージェント調査結果: 国内ギャラリー、海外/X/SaaSギャラリー、AIデザイン/デザインシステム関連の候補URL。

## 実施内容

- サブエージェントの結果を、元ネタではなく候補として扱った。
- こちらで確認したURLを `SRC-009` から `SRC-013` に整理した。
- `INF-010` から `INF-013` で、原子化、ギャラリー使い分け、B2B/AI/DX構成、AI生成UIレビュー軸を抽出した。
- `KNW-010` から `KNW-014` で、実制作に使える判断カードへ分解した。
- 既存の `KNW-003` から `KNW-009` に、状態、フロー、トークン、レスポンシブ、原子化の観点を補強した。

## 判断

- 「AIっぽくないサイト」を大量に集めるだけでは、AIに使わせられる知識にならない。
- 参照サイトは、サイト全体、セクション、判断カードへ分ける。
- KLGでは、木や知識のメタファーを装飾ではなく、情報構造と成長プロセスに接続する。
